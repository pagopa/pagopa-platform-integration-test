## Common patterns

1. **PSP Selection Timeouts in UAT Environment**: Tests #1 and #5 both failed with a timeout trying to locate `#psp-radio-PPAYITR1XXX` on `https://uat.checkout.pagopa.it/lista-psp`. This points to either missing PSP backend configuration or elevated UI rendering latency in the UAT environment.
2. **Back Navigation Routing Failure**: Tests #4 and #6 both expected to land on `/dati-pagamento` but were unexpectedly reset back to `/inserisci-dati-avviso`. This suggests a systemic issue in browser history or session state management during back navigation steps.
