## Common patterns

1. **Missing PSP Selection Element (#1 & #6)**: Both Postepay test cases failed with a timeout trying to locate `#psp-radio-PPAYITR1XXX` on the `/lista-psp` page, indicating either UAT backend data configuration issues for Postepay PSP or missing UI rendering.
2. **Unexpected Home Redirects during Navigation (#2 & #3)**: Back-navigation flows with `enablePspPage=true` failed because the application unexpectedly dropped session route context and redirected to the root URL (`https://uat.checkout.pagopa.it/`), preventing interaction with expected UI buttons.
