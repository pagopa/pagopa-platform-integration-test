## Common patterns

- **Wordline Payment Failures**: Both authenticated and unauthenticated scenarios for Wordline card configuration failed with "Il pagamento non è andato a buon fine" (Failures #1, #7), indicating a potential integration breakdown with the Wordline gateway service.
- **Missing Postepay PSP Option**: Multiple scenarios failed due to timeout locator errors for `#psp-radio-PPAYITR1XXX` on the `/lista-psp` page (Failures #2, #3), pointing to unavailable PSP test data or environment configuration issues in UAT.
- **Routing/Navigation Failures on Linear Flow**: Back-navigation tests with `enablePspPage=true` timed out looking for the 'Indietro' button because the application remained stuck at the root landing page `https://uat.checkout.pagopa.it/` rather than navigating to the target step (Failures #4, #6).
