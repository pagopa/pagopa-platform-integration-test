## Common patterns

1. **PSP Selector Timeout (`#psp-radio-PPAYITR1XXX`)**: Tests #1 and #3 both failed due to missing or delayed rendering of the Postepay PSP option on `/lista-psp`, indicating either missing test data configuration in DEV or dynamic loading delays.
