## Common patterns

- **Broken PSP Selection (#4, #8)**: Multiple scenarios timed out looking for `#psp-radio-PPAYITR1XXX` on `/lista-psp`, indicating missing test data or provider configuration in the target environment.
- **Flaky Linear Back Navigation (#3, #5)**: Back-button navigation steps timed out because the page remained on the root URL (`https://dev.checkout.pagopa.it/`) rather than completing redirect/navigation to sub-routes prior to assertion.
- **Frontend PSP Sorting Bug (#1, #2)**: Both ascending and descending PSP list sorting scenarios failed due to improper ordering logic in the application.
