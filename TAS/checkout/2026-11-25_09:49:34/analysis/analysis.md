## Common patterns

1. **PSP Selector Locators Timing Out on `/lista-psp` or incorrect pages (Failures 1, 3, 6):** Multiple payment activation tests fail due to 5-second timeouts waiting for PSP radio locators (`#psp-radio-*`). This points to slow API responses when fetching the list of available PSPs in the development environment, or race conditions where step execution proceeds before page navigation finishes.
2. **Broken Back Navigation Routing (Failures 2, 5):** Scenarios testing linear back navigation (`enablePspPage=true`) fail because the application unexpectedly drops session state/route context and redirects to the landing page root URL (`https://dev.checkout.pagopa.it/`), causing missing back button elements.
