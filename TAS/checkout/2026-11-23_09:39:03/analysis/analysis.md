## Common patterns

- **Wordline Integration Failures**: Multiple tests (`#1`, `#2`) failed due to payment authorization failures (`Il pagamento non è andato a buon fine`), pointing to a potential issue with the Wordline payment gateway mock/integration.
- **Missing PSP Options in List**: Tests `#3` and `#7` failed to find `#psp-radio-PPAYITR1XXX` on `/lista-psp`, indicating missing test data or disabled PSP configurations in the environment.
- **Navigation & Redirection Issues**: Tests `#4` and `#6` timed out looking for the 'Indietro' button because the UI redirected unexpectedly to the root route (`https://dev.checkout.pagopa.it/`).
