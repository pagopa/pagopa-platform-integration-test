## Common patterns

1. **Unexpected Home Page Redirects on Back Navigation (Failures #2 & #4):** Both linear navigation tests failed because the browser unexpectedly found itself at the base URL (`https://dev.checkout.pagopa.it/`) rather than the expected checkout step page, preventing the `Indietro` button from being located.
2. **Missing Postepay PSP in List (Failures #3 & #5):** Both authenticated and unauthenticated test flows for Postepay timed out waiting for locator `#psp-radio-PPAYITR1XXX` on `/lista-psp`, indicating the PSP option was missing from the environment data response.
