## Common patterns

1. **PSP List Inverted Sorting (Application Bug)**: Failures #1 and #4 show that ascending and descending sort checks both failed by returning the exact inverse order, indicating the frontend sorting logic or state toggle is inverted.
2. **PSP Radio Element UI Timeout (Flakiness)**: Failures #3 and #7 failed on locator `#psp-radio-PPAYITR1XXX` after 5000 ms on `/lista-psp`, pointing to asynchronous loading delays for PSP list items.
3. **Premature Step Execution / Navigation Timing (Flakiness)**: Failures #6 and #8 timed out waiting for the `Indietro` button because the browser was still on the landing URL (`https://dev.checkout.pagopa.it/`) rather than the target sub-routes.
