## Common patterns

1. **Unexpected Redirects to Root URL (`/`)**: Tests #3 and #5 both failed because navigating backward redirected the browser back to `https://dev.checkout.pagopa.it/` instead of the previous checkout step, missing the required 'Indietro' UI element.
