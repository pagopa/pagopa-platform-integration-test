## Common patterns

- **PSP Selection Locators Timeout**: Multiple tests (#4, #5, #6) fail when attempting to locate dynamic PSP radio elements (`#psp-radio-<PSP_ID>`). This points to missing PSP backend configuration in dev or latency when loading the PSP list.
- **Premature Redirects in Navigation Tests**: Linear navigation tests (#2, #7) encounter timeouts because the browser unexpectedly lands on the base URL (`/`), indicating potential unhandled session resets or missing page navigation synchronization locks.
