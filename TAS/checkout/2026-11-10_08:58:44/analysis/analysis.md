## Common patterns

1. **Unintended Redirection / Early Page Traversal**: Multiple tests (Failures 4 and 5) failed because the browser unexpectedly rested on the base URL (`https://uat.checkout.pagopa.it/`), preventing interaction with expected UI elements such as the "Indietro" button.
