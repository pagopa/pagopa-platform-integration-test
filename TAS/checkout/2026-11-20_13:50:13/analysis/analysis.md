## Common patterns

1. **NPG Payment Gateway Provider Authorization Failures**: Multiple tests across Worldpay (#3, #6) and Wordline (#8) failed at the final verification step with `"Il pagamento non è andato a buon fine"`. This points to a recurring backend integration issue during NPG payment authorization processing in the `dev` environment.
2. **PSP List Element Locating Timeouts**: Postepay card tests (#1, #5) systematically fail with a timeout waiting for locator `#psp-radio-PPAYITR1XXX` on `/lista-psp`, indicating slow page initialization or missing data rendering for Postepay.
3. **Unexpected Redirects in Back Navigation**: Both navigation tests (#2, #7) timed out looking for the back button because the browser unexpectedly bounced to the root URL (`https://dev.checkout.pagopa.it/`), suggesting a routing/session state bug when `enablePspPage=true`.
