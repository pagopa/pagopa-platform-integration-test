## Common patterns
- **Asynchronous Payment Confirmation Timing**: Worldpay scenarios failed due to evaluating success criteria while the payment was still in a pending phase ("Attendi la conferma del pagamento").
- **PSP Selection & Navigation UI Timeouts**: Multiple tests timed out after 5000ms attempting to find UI elements (`#psp-radio-PPAYITR1XXX`, `button:has-text('Indietro')`), indicating page transition latencies or missing dynamic elements on UAT environment.
- **Provider / Gateway Issues**: Wordline payments failed deterministically across scenarios due to downstream transaction rejection.
