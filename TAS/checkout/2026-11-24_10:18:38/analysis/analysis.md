## Common patterns

1. **PSP Option Missing/Timeout (`#psp-radio-PPAYITR1XXX`)**: Failures #1 and #4 both time out waiting for the Postepay radio button on `/lista-psp`. This points to an environment or mock data configuration issue where `PPAYITR1XXX` is not being populated in the DEV environment response.
2. **Unexpected Root Navigation (`https://dev.checkout.pagopa.it/`)**: Failures #2 and #5 fail to click the back button because the page unexpectedly redirects to the root homepage (`/`) instead of remaining on the expected sub-route (`/inserisci-carta` or `/scegli-metodo`).
