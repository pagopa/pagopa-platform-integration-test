## Common patterns
1. **Missing PSP Data / Config (#3, #5):** Both Postepay test cases (authenticated and unauthenticated) timed out attempting to locate `#psp-radio-PPAYITR1XXX` on `/lista-psp`. This points to missing test data or a missing configuration mock for this specific PSP in the DEV environment.
2. **Unexpected Home Redirects (#4, #6):** Back navigation scenarios unexpectedly dropped to the root URL `https://dev.checkout.pagopa.it/` instead of maintaining active checkout sub-routes (`/scegli-metodo` or `/inserisci-carta`), leading to locator timeouts for UI buttons.
