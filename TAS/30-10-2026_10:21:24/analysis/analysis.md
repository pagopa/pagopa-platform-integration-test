## Common patterns
1. **PSP Selection Timeouts**: Multiple tests fail due to a 5-second timeout waiting for `#psp-radio-PPAYITR1XXX`, indicating either an environment instability or a delay in rendering the PSP list.
2. **Back Navigation Failures**: Back-navigation tests consistently fail to locate the `'Indietro'` button, pointing to potential UI changes or component rendering issues on specific views.
3. **Error Modal Mismatches**: Notice code validation tests receive creditor error messages (`L’Ente Creditore sta avendo problemi nella risposta`) instead of the expected `PAA_PAGAMENTO_SCONOSCIUTO` message, pointing to backend error-handling discrepancies.
