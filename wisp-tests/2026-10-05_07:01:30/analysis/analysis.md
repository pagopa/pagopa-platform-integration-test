## Common patterns
All 43 failures share the exact same root cause: an `AssertionError` where the integration test suite fails to find an event with business process `receipt-ok` and status `RT_SEND_SUCCESS`. This indicates a systemic issue across single payments, cart payments, retries, and GPD integrations where payment receipts are either failing to generate or failing to emit the required tracking events to the event store.
