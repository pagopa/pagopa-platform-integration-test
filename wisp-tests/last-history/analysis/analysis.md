## Cross-suite correlation

- **WISP Suite Failure Pattern**: All WISP test failures share the exact same root cause related to the failure in generating or detecting the `receipt-ok` event (`RT_SEND_SUCCESS`) following checkout redirection. This points to a systemic backend issue in completing payment sessions and dispatching receipts across various payment types (single payments, carts, pre-existing GPD items, and stamp duties).
- **Checkout Suite Interaction**: The Checkout suite experienced UI locator timeouts on PSP selection (`#psp-radio-PPAYITR1XXX`), which directly breaks end-to-end flows that depend on successfully interacting with checkout pages. Since WISP tests rely on redirecting users to Checkout, environmental or rendering instability in Checkout could contribute to downstream session completion failures.
