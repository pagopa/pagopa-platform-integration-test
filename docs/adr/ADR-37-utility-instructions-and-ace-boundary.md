# ADR-37: Utility instruction loading and non-participant ACE boundary

- Status: Accepted

## Decision

List Python-utility-engineer in the project instruction table with Python rules.
Apply the global shared-utility documentation/reuse rule through the
[utility workflow](../workflows/python-utility-engineer/implementation.md#documentation-and-reuse-adr-37).
Assess README within documentation authority after coherent changes.

## Consequences

No independent ACE participant or scoped lessons are fabricated. Return actual
work/friction to the caller for orchestrator-owned capture; no trace writes.
Broader README needs return to an authorized writer without widening permissions.
